### 架构决策
- **三态适配层**（src/lib/supabase.ts 重写）：Supabase（主，@supabase/supabase-js 直连）→
  CloudBase mim-api（备，原 HTTP 适配器原样保留）→ 本地演示；`VITE_MIM_BACKEND` 可强制指定。
- **公开配置内联兜底**：Supabase URL + publishable key 与 CloudBase 入口一样写死为常量

  根治 EdgeOne Makers 构建读不到仓库变量 → 回退本地演示的坑。

  含 @ 输入直通兼容邮箱老账号；username 经 user_metadata 传给 profiles 触发器。

  CloudBase 模式保留 mim-api 代理。key 统一 `<uid>/<yyyy-mm>/<uuid>.<ext>`。

  `_shared/policy.ts` 可单测；CI deploy job 用 job 级 env + step 级 if 守门（复用坑①模式）。
