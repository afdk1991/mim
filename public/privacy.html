Mim 隐私政策

版本 0.0.0.0 ｜ 生效日期：2026 年 10 月 20 日 ｜ 开发者：afdk1991（个人开发者）

引言

Mim（以下简称"本应用"）是由个人开发者 afdk1991 开发并维护的内容社区类应用（含多个实用工具模块）。我们深知个人信息对您的重要性，将以高度审慎的态度处理相关信息。本政策帮助您了解：

  • 本应用不收集、不上传您的任何个人信息；
  • 本应用如何在您的设备本地处理数据；
  • 本应用在何种有限场景下发起网络请求。

请您在使用本应用前仔细阅读本政策。您开始使用本应用，即表示您已理解并同意本政策所述内容。

一、适用范围

本政策适用于 Mim 应用及其全部内置功能模块（内容社区、文章、私信、商城、出行、监控等工具模块），覆盖以下平台：

平台分发渠道
iOSApp Store
HarmonyOS（鸿蒙）华为应用市场 AppGallery
AndroidGitHub Releases / 官方分发
Windows / macOS / LinuxGitHub Releases
WebGitHub Pages / EdgeOne Pages

应用统一包名：com.afdk1991.mim。本应用各端均不包含账号注册与登录体系，除下述"网络请求说明"所列更新检查外，不与任何自有服务器交互。

二、核心承诺：我们不收集您的个人信息

  • 不收集敏感权限与数据：本应用不请求、不读取您的通讯录、相册、定位、麦克风、摄像头、剪贴板、短信、通话记录等任何权限与数据（唯一例外见"五、权限使用说明"中 Android 平台的更新安装场景）。
  • 无账号体系：无需注册、登录，不收集手机号、邮箱、身份证件、人脸等任何身份信息。
  • 无第三方 SDK：不集成任何广告、统计分析、崩溃收集、消息推送等第三方 SDK。
  • 全部为本地演示数据：应用内出现的动态、评论、私信、商品、订单、支付流程等内容均为设备本地模拟的演示数据，不代表真实用户，不产生真实交易，不收集任何支付账户信息。

三、本地数据存储

为提供离线可用的体验，本应用会在您的设备本地存储（浏览器 localStorage / 应用沙盒目录）中保存：

  • 演示数据：动态、文章、评论、私信以及各工具模块产生的状态；
  • 偏好设置：主题（浅色 / 深色）、浏览历史等。

上述数据仅保存在您的设备上，不会同步或上传至任何服务器。您可随时完全清除：

  • 应用内重置：点击应用顶部的 ♻️ 重置按钮，一键恢复初始演示数据；
  • 彻底删除：卸载本应用（移动端 / 桌面端），或在浏览器中清除本站点数据（Web 端）。

四、网络请求说明

本应用仅在一类场景下主动发起网络请求——版本更新检查：

  • 移动端与桌面端在启动约 8 秒后，向 GitHub Releases（github.com）拉取更新清单文件（manifest.json / latest.json），检查频率不低于每 6 小时一次；
  • 该请求仅传输应用当前版本号用于比较，不携带任何设备标识、个人信息或使用数据；
  • 发现新版本时：Android 端将下载新版安装包并经 SHA-256 校验后提示安装；iOS 与 HarmonyOS 端仅弹窗提示，并引导您前往官方应用商店更新。

此外：

  • Web 端访问页面时，静态资源由第三方云服务（GitHub Pages / EdgeOne Pages）分发，该等服务商可能出于安全与加速目的按其自身隐私条款处理基本网络信息（如 IP 地址）；
  • 本应用不存在任何其他网络通信。

五、权限使用说明

平台权限用途拒绝后果

Android安装应用（REQUEST_INSTALL_PACKAGES）仅在您确认更新时调起系统安装器无法自动安装更新

六、数据存储与保留

  • 本地数据自生成起保留，直至您主动重置、清除站点数据或卸载应用；
  • 本应用当前无自有服务器，不在任何服务器端保留用户数据。

七、数据安全

  • 更新完整性校验：Android 更新包经 SHA-256 摘要校验，桌面端更新经 Ed25519（minisign）数字签名验证，防止更新内容被篡改；
  • 本地存储保护：数据保存于操作系统沙盒或浏览器存储内，受系统安全机制保护；
  • 由于本应用不传输任何个人信息，不存在个人信息泄露、篡改、丢失的网络传输风险面。

八、未成年人保护

  • 本应用内容为技术与产品演示性质，不含面向未成年人的付费或真实社交功能；
  • 我们不会有意收集未成年人的任何个人信息；
  • 监护人如对未成年人使用本应用有疑问，可通过下述方式联系我们。

九、您的权利

依据《中华人民共和国个人信息保护法》等法律法规，您享有以下权利：

  • 知情权与决定权：本政策已完整披露本应用全部数据处理活动；
  • 删除权：通过应用内 ♻️ 重置、卸载应用或清除站点数据，即可删除全部本地数据；
  • 由于我们不收集任何个人信息，一般不存在需要更正、转移或撤回同意的个人信息；如未来数据处理方式变化，我们将依法为您提供相应途径。

十、政策变更

  • 若未来功能演进影响数据处理方式（例如引入云同步、账号体系），我们将在本页面发布更新版本并更新生效日期；
  • 重大变更前，我们将在应用内显著提示，并在依法需要时重新征求您的同意。
