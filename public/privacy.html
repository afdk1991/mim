Mim 隐私政策

版本 0.0.0.2 ｜ 生效日期：2026 年 10 月 26 日 ｜ 开发者：afdk1991（个人开发者）

引言

Mim（以下简称"本应用"）是由个人开发者 afdk1991 开发并维护的内容社区类应用（含多个实用工具模块）。我们深知个人信息对您的重要性，将以高度审慎的态度处理相关信息。本政策帮助您了解：

  • 本应用收集哪些信息（仅限注册登录与内容发布所必需的信息）；
  • 本应用如何在您的设备本地与云端服务器处理数据；
  • 本应用在何种场景下发起网络请求。

请您在使用本应用前仔细阅读本政策。您开始使用本应用，即表示您已理解并同意本政策所述内容。

一、适用范围

本政策适用于 Mim 应用及其全部内置功能模块（内容社区、文章、私信、商城、出行、监控等工具模块），覆盖以下平台：

平台分发渠道
iOSApp Store
HarmonyOS（鸿蒙）华为应用市场 AppGallery
AndroidGitHub Releases / 官方分发
Windows / macOS / LinuxGitHub Releases
WebGitHub Pages / EdgeOne Pages

应用统一包名：com.afdk1991.mim。本应用各端统一使用同一账号体系：账号经云端身份服务（Supabase Auth）认证，您发布的内容与账号数据存储于云端后端（Supabase 数据库 / 腾讯云 CloudBase 云函数），未登录时以游客身份仅在本机使用。

二、我们收集哪些信息

  • 不收集敏感权限与数据：本应用不请求、不读取您的通讯录、相册、定位、麦克风、摄像头、剪贴板、短信、通话记录等任何权限与数据（唯一例外见"五、权限使用说明"中 Android 平台的更新安装场景）。
  • 账号信息：注册时您需要提供用户名与密码（可选提供邮箱）。密码由云端身份服务加密存储，本应用不接触密码明文；我们不收集手机号、身份证件、人脸等身份信息。
  • 您主动发布的内容：动态、文章、评论、私信、头像与媒体附件等，用于在您的账号下存储与展示；这些内容仅由您主动提交。
  • 交易与钱包记录：您在应用内的充值、购买、订单记录。不收集银行卡号、支付密码、验证码等信息；扫码支付由您在第三方支付应用内自行完成，本应用仅保存您主动提交的付款凭证（如交易单号）用于对账。
  • 无第三方 SDK：不集成任何广告、统计分析、崩溃收集、消息推送等第三方 SDK。
  • 不出售、不共享：我们不会出售您的个人信息，也不会向无关第三方共享；仅为提供功能所必需而使用上述云端服务商。

三、本地缓存与云端存储

为提供离线可用的体验，本应用会在您的设备本地（浏览器 localStorage / 应用沙盒目录）缓存以下数据，并按登录身份隔离：

  • 内容与工具状态：动态、文章、评论、私信的本地副本，以及钱包、成长、发布记录、会员等各模块产生的状态；
  • 偏好设置：主题（浅色 / 深色）、浏览历史等。

登录后，内容与账号数据以云端为真源存储在云端后端，本地保存仅为加速与离线可用；未登录（游客）时数据仅保存在本机。您可随时清除：

  • 应用内重置：点击应用顶部的 ♻️ 重置按钮，清除本机缓存内容；
  • 云端删除：登录后在应用内删除您的内容，云端对应记录同步删除；
  • 彻底删除：卸载本应用（移动端 / 桌面端），或在浏览器中清除本站点数据（Web 端）。

四、网络请求说明

本应用在以下场景下主动发起网络请求：

  • 账号与内容同步：注册 / 登录 / 退出，以及内容发布、评论、私信、媒体上传等操作，会请求云端后端（Supabase / 腾讯云 CloudBase），仅传输完成该操作所必需的数据与您的登录凭证；
  • 版本更新检查：移动端与桌面端在启动约 8 秒后，向 GitHub Releases（github.com）拉取更新清单文件（manifest.json / latest.json），检查频率不低于每 6 小时一次；该请求仅传输应用当前版本号用于比较，不携带任何设备标识、个人信息或使用数据；发现新版本时：Android 端将下载新版安装包并经 SHA-256 校验后提示安装；iOS 与 HarmonyOS 端仅弹窗提示，并引导您前往官方应用商店更新；
  • 在线素材检索：当您主动使用在线素材 / 漫剧发现功能时，应用会向 mim-api 代理或开放素材服务（Openverse、Wikimedia Commons）发送您的检索关键词，不携带账号信息。

此外：

  • Web 端访问页面时，静态资源由第三方云服务（GitHub Pages / EdgeOne Pages）分发，该等服务商可能出于安全与加速目的按其自身隐私条款处理基本网络信息（如 IP 地址）；
  • 本应用不存在上述之外的其他网络通信。

六、数据存储与保留

  • 本地缓存：自生成起保留，直至您主动重置、清除站点数据或卸载应用；
  • 云端数据：账号信息与您发布的内容保存在云端后端（Supabase 数据库 / 腾讯云 CloudBase 云函数），保留至您主动删除内容或注销账号；账号注销后，账号及其关联内容将在 15 个工作日内删除；
  • 服务运行日志：云端服务商可能按行业惯例保留短期运行日志（如请求时间、错误信息）用于安全防护与故障排查，不包含您发布内容的正文。

七、数据安全

  • 传输加密：与云端后端的所有通信均通过 HTTPS（TLS）加密传输，登录凭证与内容数据不以明文经过网络；
  • 账号隔离：云端数据库启用行级安全策略（RLS），您的数据仅能被您的账号读取与修改；密码由云端身份服务加密存储，本应用不接触密码明文；
  • 更新完整性校验：Android 更新包经 SHA-256 摘要校验，桌面端更新经 Ed25519（minisign）数字签名验证，防止更新内容被篡改；
  • 本地存储保护：数据保存于操作系统沙盒或浏览器存储内，受系统安全机制保护；
  • 尽管我们已采取上述措施，任何网络传输或电子存储方式都无法保证绝对安全；如发生个人信息安全事件，我们将依法及时告知您并向主管部门报告。

八、未成年人保护

  • 本应用面向具备完全民事行为能力的用户提供内容社区与工具服务，不专门面向未成年人设计；
  • 我们不会有意收集未成年人的个人信息。若您是未成年人，请在监护人陪同下阅读本政策，并在取得监护人同意后使用本应用；
  • 监护人如发现未成年人未经同意向我们提供了个人信息，可通过下述方式联系我们，我们将在核实后删除相关账号与数据。

九、您的权利

依据《中华人民共和国个人信息保护法》等法律法规，您享有以下权利：

  • 知情权与决定权：本政策已完整披露本应用的各项数据处理活动；
  • 查阅与更正权：您可在应用内随时查看并修改您的账号资料与已发布内容；
  • 删除权：在应用内删除内容会同步删除云端对应记录；点击应用内 ♻️ 重置可清除本机缓存；账号注销后，账号及关联数据将在 15 个工作日内删除；
  • 注销权：您可通过本政策列明的联系方式提出账号注销申请；
  • 撤回同意：您可随时退出登录并停止使用本应用，撤回同意不影响撤回前基于您的同意已进行的处理。

十、政策变更

  • 若数据处理方式发生变化，我们将在本页面发布更新版本，并同步更新生效日期与版本号；
  • 重大变更前，我们将在应用内显著提示，并在依法需要时重新征求您的同意。
