# Mim 项目互联网资源调研报告

> **调研对象**：F:\合并项目\Mim（自托管全栈内容社区 + 商城 + 工具台项目）
> **检索日期基准**：2026-10-29（Asia/Shanghai，所有免费额度/许可证/版本均以该日期现行官方页为准）
> **调研方式**：只读互联网调研（官方文档 / GitHub / npm / 各平台定价页 / 技术博客），未修改 Mim 任何代码与配置
> **证据分级**：✅ 已核实官方（官方文档/定价页/官方仓库直接核对）；⚠️ 仅第三方称（社区/博客口径，需二次确认）
> **优先级定义**：**立即用**（零成本/低成本、接入半天内、解决真实缺口）/ **值得评估**（有价值但需先做小范围验证）/ **仅参考**（与 Mim 主路线不直接适用或冲突）

**Mim 技术栈基线**（已核实项目文件）：前端 React 18.3 + Vite 8.3 + TS 5.9 纯 SPA（自研 hash 路由 + 自研轻量 UI + 自研 data 层，运行时依赖仅 react/react-dom/@capacitor）；后端 server/ 为 node:http 零框架 + pg（PostgreSQL 8787，REST /api/rest/:table + RPC /api/rpc/:fn）；原生壳 android(Capacitor 8.5.3)/ios/harmony/src-tauri(Tauri 2)；已有 `.edgeone/` 部署目录、`worker/`（wrangler.jsonc）、`.github/`、`.gitee/`、自研 IPlatfformAdapter 平台适配层、自研验证脚本（verify-routes/backend/mobile 等）。

**硬约束**：全程无 Docker；部署 GitHub Actions + 自有宿主机（systemd + nginx + PostgreSQL）；主路线自托管；用户在中国（宁波），国内合规（备案/审核）为现实约束。

**交付结构**：本报告为六维度结论 + Top 10 速览 + 不建议引入清单；每个维度的完整条目表（含全部来源 URL）见同目录 `artifacts/01~06-*.md` 分文件。
