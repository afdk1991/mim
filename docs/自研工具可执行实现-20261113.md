### 4.3 换域名 dry-run / apply 与 diff

样本 `.tmp/dump.sql`（apply 前）：

```sql
INSERT INTO wp_options VALUES ('siteurl', 'https://old.com');
INSERT INTO wp_options VALUES ('home', 'http://www.old.com/blog');
INSERT INTO wp_posts VALUES (1, 'See http://old.com/page and https://www.old.com/x');
INSERT INTO wp_postmeta VALUES (2, 's:18:"http://old.com/abc";');
```

dry-run 摘要：`{ "mode": "text", "dryRun": true, "backup": null, "replacements": 5, "changed": true }`（文件未改）。

apply 摘要：`{ "dryRun": false, "backup": { "backup": ".tmp/dump.sql.bak", "created": true }, "replacements": 5 }`。

apply 后文件：

```sql
INSERT INTO wp_options VALUES ('siteurl', 'https://new-mim.com');
INSERT INTO wp_options VALUES ('home', 'http://www.new-mim.com/blog');
INSERT INTO wp_posts VALUES (1, 'See http://new-mim.com/page and https://www.new-mim.com/x');
INSERT INTO wp_postmeta VALUES (2, 's:22:"http://new-mim.com/abc";');
```

序列化串 `s:18:"http://old.com/abc";` → `s:22:"http://new-mim.com/abc";`：长度按新内容 UTF-8 字节重算（7 + 11 + 4 = 22）。`.bak` 保留原始内容。

## 五、与平台 `/tools` 目录的对接方式

- 平台路由 `services/mim-api/src/routes/tools.ts` 与表 `schema.d/21-tools.sql` 的 `mim_tools` 已有三条种子记录，`slug` 与本目录一一对应：

| `mim_tools.slug` | 本目录实现 | 可分发产物 |
| --- | --- | --- |
| `quick-build-wp` | `tools/quick-build-wp/` | `--emit` 生成的建站脚本 `.sh` |
| `db-replace-domain` | `tools/db-replace-domain/` | CLI 工具包 / 说明 |
| `liudun-waf` | `tools/liudun-waf/` | 网关 CLI、`--emit-nginx` 生成的 `.conf` |

- `mim_tools` 记录的 `download_url` / `doc_url`（安装包 / 仓库链接）可指向本目录产出的脚本或配置；**平台侧只做元数据分发与链接展示，不在服务端执行脚本、不起 WAF 进程**。
- 执行环境归属：建站脚本在用户自有 Linux 主机运行；WAF 网关由站点 / 网关侧部署；换域名工具由管理员在数据库所在环境运行。
- 本目录不被 `services/mim-api`、`apps/web` 或主构建引用；前端仅通过工具详情页外链访问产物。

## 六、明确未做 / 受限于环境的部分

1. **无 Docker / 无 MySQL / 无 PHP**：建站脚本未在真实 Linux 主机执行过，交付物是「脚本生成器 + 静态自检 + `bash -n` 语法校验」；脚本里的真实安装、建库、下载 WordPress 动作在目标主机发生，测试全程不联网、不下载真实 WordPress。
2. **SQLite 依赖 Node 22 内置 `node:sqlite`**（实验性 API，运行时有 ExperimentalWarning，仅 SQLite 模式出现）；`WITHOUT ROWID` 表无 rowid，会被跳过并计入 `skippedTables`。
3. **序列化覆盖范围**：处理一维 `s:<len>:"..."` 串及常见 `a:` 容器内的 `s:` 串；非常规转义 / 二进制序列化格式未覆盖。
4. **WAF 规则为基础正则集**：未做语义分析、文件上传检测、分布式 CC 维度（按 IP+路径）、人机校验；导出的 nginx 配置未在真实 nginx 上加载校验。
5. **换域名仅处理文本与 SQLite**：MySQL 在线库模式未实现（本机无 MySQL）；二进制字段、序列化对象嵌套过深的场景未覆盖。
6. 未新增 npm 依赖、未改主仓库任何既有源码 / 配置 / 工作流、未执行 git 提交或推送。
