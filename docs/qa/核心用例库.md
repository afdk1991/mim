## 0. 字段约定

| 字段 | 说明 |
| --- | --- |
| 用例ID | `<域缩写>-<序号>`，域缩写见下表 |
| 优先级 | P0=阻断（不可发布） / P1=严重 / P2=一般（分级定义见 `docs/qa/测试策略.md` 第 2 节） |
| 自动化状态 | **已自动化**（注明脚本）/ **手工** / **未覆盖** |
| 负责人 | QA=质量 / BE=后端 / FE=前端 / PM=产品 |

| 域缩写 | 域 | 主要入口 |
| --- | --- | --- |
