# 借鉴外部标杆落地（2026-11-25，V0.0.18-preview）

> 本轮把两份外部标杆调研矩阵中**可在 Mim 当前体量内直接落地**的信息架构、信任表达、反馈可见性与个人聚合做法收口进代码；不抄素材、不抄文案、不抄代码，不碰同机 WordPress，不建备份。

## 1. 本轮口径与边界

- **只读公开页调研**：两份矩阵均为首页 + 至多一个关键页的只读采样，未绕登录、未绕付费墙、未批量抓取；未复制任何素材 / 文案 / Logo / 代码。
- **不碰 `laal.top`**：裸域 `https://laal.top` 是同机另一套 WordPress（zibll 主题）站点，本轮全程只读其作为参照面，未改动该站任何设置；Mim 前端为 `https://zy.laal.top`，API 为 `https://api.laal.top`。
- **不建备份**：项目铁律不创建任何数据库备份（无 `.bak`、无 `db.backup()`），本轮未产生备份文件。
- **未访问 hznzcn.com**：按既定偏好，全程未访问 `https://www.hznzcn.com` 及 www/m 镜像与图床；已入库的相关商品保留不动。
- **代码边界**：本轮只做收口与必要最小修补（门禁脚本清单补登、注释口径更正），不改既有业务逻辑；未新增第三方依赖。
- **版本**：semver `0.0.17` → **`0.0.18`**（6 个 `package.json` 同步，展示 `V0.0.18-preview`）。

## 4. 三分类取舍

### 4.1 可直接实现，本轮已做

见 §3 落地清单 1–8。

### 4.2 需产品 / 法务决策，本轮未做（含决策点）

- **合规正文法律条款**：四篇骨架中所有「待补充」项（采集字段清单、个性化推荐口径、保留期限、第三方共享名单、责任限制 / 免责条款、争议解决、退款范围与条件、客服渠道等）需法务复核后填写；**决策点**：责任限制与免责情形、退款规则、第三方服务商清单由谁确认、生效日期口径。
- **定价 / 套餐对比表**：Stripe / Shopify / HubSpot 式公开费率、席位、限额同屏对比；**决策点**：Mim 是否做付费档位、定价模型（用量 / 席位 / 包年），当前无商业定价决策，不落对比表。
- **会员 / 营销模板库与自动化流程**：Mailchimp / 有赞式模板沉淀；**决策点**：是否建内容模板库与自动化营销链路。
- **多榜单与算法排序前台入口**：掘金 / GitHub 式推荐 / 最新 / 关注切换与周期热度榜；**决策点**：自有内容量与算法权重调试节奏。
- **AI 参与声明 / 作者身份分级徽章**：少数派式署名区显性标注；**决策点**：是否引入 AI 辅助内容标注与作者等级体系。
- **隐私承诺卖点化表述**：Obsidian 式数据归属 / 加密承诺上公开首页；**决策点**：服务侧数据留存与加密口径定稿后再对外表述。

### 4.3 不适用 / 有前提，本轮不迁移

- **持牌金融 / 支付产品承诺**：Revolut 储蓄利率、证券交易；PayPal / Stripe 资金托管与争议裁决——Mim 无牌照，不可自建对等承诺，仅作为应用方接入既有支付渠道。
- **医疗诊疗级内容**：NHS / Mayo 的分诊与临床建议合规责任极重，Mim 不进入该内容赛道。
- **SaaS 席位计费 / 企业级权限粒度**：Todoist / HubSpot / 金蝶的席位订阅与大客户流程，与当前体量不匹配。
- **CAD 工业模型库 / 建筑媒体大图版权**：GrabCAD / ArchDaily 的文件托管与署名版权生态超出内容社区范围。
- **代码协作工作流**：GitHub 的 PR / Issue / Discussions 对象是仓库而非帖子，社交图谱不可复刻。
- **编辑器强策展与付费会员墙**：少数派 PRIME、简书付费专题的策展强度与付费墙口径，与当前开放阅读定位不同。
- **登录墙后内容**：Strava 俱乐部页等跳转登录墙，本轮未进入、未绕登录取证，相关结论不写入矩阵。
