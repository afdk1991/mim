# 漫剧片单更新 · 变更总结

> 模块：漫剧 Manju（`#/manju`）
> 上一轮：ee31bd4（2026-10-20）｜本轮：彻底下线红果外部目录（未提交）

## 1. 变更背景

- **上轮（ee31bd4）**：把外部片单里的红果短剧 AI 剧场 9 部（平台版权内容）全量替换为授权可验证的开放内容；
  但当时**保留了红果外部目录（2010 条公开元数据）的浏览链路**。
- **本轮**：彻底下线红果外部目录。首页不再有独立的「外部片单索引」入口，
  「站内精选」成为站内唯一片单索引（18 部 · 公版动画 / Blender 开源电影）。

## 3. 本轮变更明细

### src/manju.tsx

- **删除红果数据模型**：`HgItem` / `HgIndex` 两个接口
- **删除红果 fetch 适配层**：`EXT_FILES` / `HG_STEP` / `hgCache` / `extUrl()` / `isHgItemRaw()` / `loadHgIndex()` / `loadHgItems()`
- **删除红果视图组件**：`ExtIndexView`（分类索引页）、`HgCover`（红果封面）、`HgListView`（分批列表）、`ExtWatchView`（条目页）
- **删除死代码**：`MjLoading`（加载态，仅被红果视图使用）
- **视图类型收敛**：
  - `MjView` 由 5 态（`home` / `extIndex` / `extList` / `extWatch` / `play`）→ **3 态**（`home` / `list` / `play`）
  - `play.from` 由 `'home' | 'pd'` → `'home' | 'list'`
- **首页 `HomeView`**：
  - 移除独立的「外部片单索引」入口卡片
  - 移除 `extTotal` / `onOpenExt` 两个 props
  - 新增 `onViewAll`：「站内精选」分区头右侧增加 **「全部 18 部 ›」** 按钮，进入全量列表
  - Hero 文案改为「站内精选 · 公有领域 / CC 授权真实内容，全部可看、无版权争议」
- **`ManjuPage`**：移除 `idx` / `idxErr` / `idxReload` 状态与红果索引加载副作用；移除 `hgTotal` / `extTotal` 计算；`goBack` / `renderBody` 分支同步收敛
- **页脚**：删除红果版权声明句，只保留站内精选授权说明

### src/manju.css

- 新增 `.manju-section-head-row`（分区头带操作按钮时两端对齐）
- 删除红果/外部片单死样式：`.manju-ext-cats` / `.manju-ext-cat` / `.manju-attrib` / `.manju-hg-grid` / `.manju-hg-cover*` / `.manju-extwatch*` / `.manju-ext-entry*` / `.manju-ext-arrow` / `.manju-ctrls` / `.manju-loading`

### public/external/

### 8.2 在线发现（三条检索通道）

| 通道 | 端点 | 授权过滤 | 说明 |
|---|---|---|---|
| Openverse 视频 | mim-api `/openverse/videos` | `license_type=commercial` | 代理转发 + 5 分钟服务端缓存 |
| Openverse 音频 | mim-api `/openverse/audio` | 同上 | 映射为 `audioUrl` |
| Wikimedia Commons 视频 | `commons.wikimedia.org/w/api.php`（直连，`origin=*`） | 取文件页 `LicenseShortName` | `generator=search + prop=videoinfo` 单请求取直链，AI 生成短片主通道 |

- 前端网络层：`src/lib/openverse.ts`（`searchOpenverse` / `searchCommons` /
  `fetchWithTimeout` 15s / `OvRateLimitError` / `licenseLabel` 等纯函数）。
- 代理存在理由（审计结论）：Openverse API 浏览器 CORS 支持不稳定（外部实测称未启用），
  且匿名限流仅 5 次/小时；mim-api 代理同时解跨域、缓存、提额三问题。
- 提额（可选）：Supabase 侧 `supabase secrets set OPENVERSE_CLIENT_ID=... OPENVERSE_CLIENT_SECRET=...`
  （CloudBase 侧为 `MIM_OV_CLIENT_ID` / `MIM_OV_CLIENT_SECRET`），注册后 10,000 次/天；
  未配置则匿名 + 缓存兜底。
- UI：来源 chips（三通道单选）+ preset 关键词 chips + 最近搜索（localStorage 8 条）+
  分页「加载更多」+ 结果计数；429 有专属文案；收入片单按 id 去重（「✓ 已加入」disabled）。
