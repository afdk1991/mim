- Top3 关键发现：

  2. **BE-002（待建议）** `seckill_release` 按 `(session_id, user_id)` 整行删锁并整体回补累计 `qty`，同一用户多笔/多单累计抢锁时，取消其中一笔会错误释放其它在途锁占用的库存。
  3. **BE-003（待建议）** 对象存储允许 `image/svg+xml` 上传且 GET 接口内联返回，同域部署下构成 stored-XSS 向量。
