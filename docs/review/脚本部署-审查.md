## 三、已排除项（核查后认为无问题）

- **危险 shell 模式**：三个 `.sh`（init-multi-remote.sh / install.sh / init-db.sh）均无 `curl|sh`、无未引用变量滥用、无 `rm -rf` 变量通配；`set -euo pipefail` 齐备。根文档（INSTALL.md:120,188、deploy/README.md:44）中的 `curl … | bash` 均为 nvm / NodeSource 官方安装指令的标准写法，非本项目脚本。
- **硬编码秘密/令牌**：install.sh 的 `DB_PASS`/`JWT` 由 node crypto 随机生成（install.sh:90-91），不写入仓库；`.gitignore:11-13,67-69` 正确排除 `.env`/`server/.env`；`git ls-files` 确认无 env 文件入库。workflows 中密钥均走 `secrets.*`。
- **行尾编码**：三个 `.sh` 全部纯 LF（逐字节检测 CRLF=0），无 Windows CRLF 污染。
- **workflow 触发条件冲突**：build.yml（push/PR→main）与 deploy.yml（push→main）触发重叠但作业目标不同（Pages vs SSH 部署），concurrency 分组各自隔离，无互相取消问题。
- **action 版本固定**：checkout/setup-node/upload-pages-artifact/deploy-pages/upload-artifact/tauri-action 均固定主版本号，符合惯例。
- **install.sh sed 模板替换**：`WorkingDirectory=/EnvironmentFile=/ReadWritePaths=`（mim-server.service）与 `root /opt/mim/dist;`/`server_name _;`/`127.0.0.1:8787;`（nginx-mim.conf）均逐条比对命中，替换模式有效。
- **sync-pull.mjs / verify-backend.mjs / server-health.mjs / version-check.mjs / init-multi-remote.sh / lib/browser.mjs / browser-check.mjs / gen-page-stubs.mjs**：逻辑自洽，未见阻断性 bug。
