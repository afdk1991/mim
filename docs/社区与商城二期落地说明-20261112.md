# 社区与商城二期落地说明（2026-11-12）

本轮按用户「不要只给报告、不要只本地预览」的要求，直接把社区论坛半成品补齐到可用闭环，并把安全外围接进真实请求链路。

## 一、本轮真正新增并跑通的能力

### 1. 社区帖子形态闭环
- 新增 `community_thread_media`：图集 / 视频 / 剧集帖可写多张图片或视频，详情按顺序返回 `media[]`；前端渲染图片网格与 `<video controls>` 播放器。
- 新增 `community_poll_options` / `community_poll_votes`：投票帖支持 2–10 个选项、计票、百分比、当前用户选择，支持改投。
- 发帖校验：`gallery` / `series` 至少一张图，`video` 至少一个视频，`poll` 至少两个选项；媒体地址必须为站内相对路径或通过 SSRF 校验的公网 http(s) URL。
- 发帖与回复统一过 `auditText` 内容审核（未配置百度审核时明确标记 `provider=none` 并放行）。

### 2. 收藏、评分与排序
- 新增 `community_favorites`：帖子收藏开关、我的收藏列表。
- 新增 `community_ratings`：1–5 星评分，重复评分 upsert，返回平均分与评分人数。
- 帖子列表 `sort` 支持 `latest | hot | views | replies | favorites | rating`；卡片展示收藏数与评分。
- 详情返回 `favorited`、`rating_avg`、`rating_count`、`my_rating`。

### 3. 付费板块
- 新增 `community_board_memberships`：板块付费加入，VIP 免单，否则余额扣款并写消费流水。
- `hasBoardAccess` 统一校验：免费板块直接放行；付费板块要求已加入或 VIP 有效。
- 板块列表返回 `price_cents` 与 `joined`；未加入时详情正文、回复与媒体全部隐藏，前端区分「板块需加入」与「帖子需解锁」两种付费墙。
- 付费板块未加入时发帖返回 403。

### 4. 积分消费与转账
- `POST /wallet/points/transfer`：按 Mim ID（纯数字）转积分，双方各写一条流水；余额不足、转给自己、接收方不存在均明确拒绝。
- 前端钱包页新增「接收方 Mim ID + 积分 + 转积分」表单。

### 5. 支付通道
- 微信支付：新增 Native 下单、API v3 请求签名（RSA-SHA256）、回调验签、AES-256-GCM 解密、金额与 `trade_state` 校验；配置齐全才在渠道列表显示可用。
- 支付宝：新增手机网站支付 `alipay.trade.wap.pay`，`createIntent` 支持 `channel=qr|wap|app`，wap/app 返回可跳转的 `pay_url`。
- `express.json` 保留 `rawBody`，微信回调验签使用原始报文字节，避免 JSON 重排导致验签失败。

### 6. 安全外围
- `GET /auth/captcha`：本地 5 位 SVG 图形验证码，答案只存 sha256，10 分钟过期、一次性消费。
- `MIM_CAPTCHA_REQUIRED=1` 时 `/auth/code` 强制校验验证码；登录页在开关开启时自动展示验证码图片、输入框与「换一张」。
- `GET /security/status`：区分验证码是否强制、内容审核是否配置。
- `POST /reports`：举报帖子 / 回复 / 资产 / 商品 / 用户，24 小时每账号最多 5 条，超限 429 `RATE_LIMITED`。
- `GET /reports/mine`、`GET /reports/admin`、`PUT /reports/:id`：运营处置可隐藏帖子、删除回复、下架商品、隐藏付费资产。
- `assertPublicHttpUrl`：只允许 http/https，拒绝 localhost、私网、回环、链路本地、100.64、组播与 IPv6 映射私网，降低 SSRF 风险。
- 百度文本审核：`MIM_BAIDU_AUDIT_API_KEY` / `MIM_BAIDU_AUDIT_SECRET_KEY`，client_credentials 换 token 并缓存 25 小时。

## 六、P1 社区闭环与前台渲染（2026-11-13 V0.0.8）

本轮把上一版审计中「半成品」的社区/付费资产前台补齐为可用闭环，代码与测试均已落地。

### 1. 付费图库 / 付费视频前台
- `paid_assets.media_json` 保存媒体数组；详情在未解锁时返回空数组，解锁后返回 `[{kind,url,poster_url}]`。
- 发布接口支持 `media`（最多 30 条），图库至少一张图、视频必须有视频地址，逐条走 `assertPublicHttpUrl` SSRF 校验。
- 前端 `CommerceCenter.tsx` 详情渲染图片网格与 `<video controls>` 播放器；发布表单支持每行一个媒体地址。
- 种子资产补媒体：图库 9 张 `/catalog/*.jpg`，付费视频两条 `/demo/*.mp4` 与封面。

### 2. 公共页面区块与「论坛设为首页」
- 新增公开 `GET /api/v1/site/config`，返回 `home_view`、主题、站点与语言配置，匿名可读。
- `page_blocks` 公共渲染器 `apps/web/src/views/PageBlocks.tsx`，支持 hero / features / tabs / notice / announcements / product_grid。
- 商城首页与论坛页顶部接入区块；根路径读取 `home_view`，为 `community` 时跳转论坛，深链接不拦截。

### 3. 板块权限与论坛闭环
- `community_boards` 增加 `visibility`、`post_min_level`、`created_by`、`moderator_id`；新增 `community_board_follows`。
- followers 板块未关注时列表 `locked=1`、发帖 403；关注后解锁；付费板块与关注门槛同时校验，版主/创建者豁免。
- `POST /community/boards/:slug/follow` 关注开关；`POST /community/boards` 允许 Lv.5 或 VIP 创建（每人最多 3 个，创建者即版主）。
- 问答帖 `POST /community/threads/:id/accept` 仅提问者可采纳本贴回复，详情返回 `accepted_post`。
- 帖子支持 `episodes`（剧集目录，series 至少一集），详情渲染播放器；`DELETE /community/threads/:id` 作者/版主/创建者软删。
- 前端补齐创建板块、关注、采纳、删帖、剧集目录、付费墙区分与公告区块。
