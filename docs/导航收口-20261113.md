# 导航收口（2026-11-13）：16 项一级 → 12 项平铺

## 1. 结论

侧栏一级入口由 **16 项** 收敛为 **12 项**，**按固定顺序平铺、不渲染分组标题**；被收敛的 4 项**页面与路由一条不删**（直链、统一搜索、站内跳转全部照旧可达），只是不再各占一行。

| 处置 | 原一级入口 | 归并到 | 依据 |
|---|---|---|---|
| 合并 | 商品列表 | 商城 | 同一批商品的两种呈现：商城是「分类 + 卡片 + 详情面板」，商品列表是「密集列表 + 加购」，重复消费同一份 `/modules` 数据 |
| 合并 | 圈子 | 社区 | 圈子是社区里的成员制板块（成员制社群与论坛 board 同属社区域），放在一级会与「社区」争夺同一批用户心智 |
| 合并 | 入口配置清单 | 导航站 | 两者都是「目录」：导航站是站外资源目录，入口配置清单是站内 44 个入口的模块目录，合并后一个「站点」入口即可覆盖 |
| 合并 | 部署汇总 | 版本 | 两者都是元信息核对：版本回答「发了什么」，部署汇总回答「发到哪、成没成」，同一阅读场景 |
| 改名 | 社区与商城 | 社区 | 社区页内确有独立商城，但一级入口叫「社区与商城」会与真正的「商城」重名混淆 |
| 保留 | 商城 / 购物车 / 个人中心 / 社区 / 漫剧 AI 剧 / 聊天 / 商业化中台 / 导航站 / 统一搜索 / 版本 / 自研工具 / 公告动态 | —— | 分别承担交易、社区、创作、经营、站点检索与内容职责，没有第二个入口可替代 |

## 2. 最终侧栏（12 项平铺，无分组标题）

商城 · 购物车 · 个人中心 · 社区 · 漫剧 AI 剧 · 聊天 · 商业化中台 · 导航站 · 统一搜索 · 版本 V0.0.10 · 自研工具 · 公告动态

> 2026-11-13 二次调整：初版曾给这 12 项加 6 个分组标题（交易与账户 / 社区 / 创作与沟通 / 经营 / 站点与版本 / 工具与内容），按用户「删除侧栏 12 项按 6 组排列」的指令，分组标题、`group` 字段与 `.nav-group` 样式一并删除，回到 12 项平铺。

## 3. 实现口径（可回滚）

- `apps/web/src/App.tsx`：`navDefaults` 增加可选 `hidden` 字段；「合并进上级」的 4 项标 `hidden: true`；侧栏过滤条件为 `item.visible && !item.hidden`。
- `apps/web/src/appearance.ts`：`NavDefault` 同步扩展 `hidden?`；`mergeNavItems` 的 `...item` 展开会把字段透传给侧栏。
- 新增「合并入口条」`subnav`：商城页顶部给「商品列表（列表视图）」、社区页给「圈子（成员制社群）」、导航站给「入口配置清单（44 个入口）」、版本页给「部署汇总（12 个部署项）」；二级页反向给「返回商城 / 返回社区 / 返回导航站 / 返回版本」。
- 后台 `nav_items` 只能改文案与显隐，**不能把 `hidden` 项拉回侧栏**（避免运营一次误配把收口推翻）。
- 回滚方式：删掉 4 处 `hidden: true` 即恢复 16 项平铺，无需改路由与页面。

## 5. 遗留阻断（与本轮导航改动无关，但会影响「全平台正常」）

1. **生产主机不可用**：`https://mim.mixm.top/health` 本机 `IOException：目标计算机积极拒绝（443）`；Cloudflare Pages 的 `/api` 反代回源返回 **521**，说明源站未在提供服务。
2. **部署私钥被服务器拒绝**：CI run 43441455984 的「发布到生产服务器」在 `scp deploy/deploy.sh` 处 `Permission denied (publickey,password)`（exit 255）；本机 `~/.ssh/mim_deploy` 对 `root@ / ubuntu@ / mim@115.159.159.11` 同样被拒。该失败在**本轮改动之前**的 run 43438813684（@43b3b08）已同样出现。
3. 因此导航收口在静态镜像（Cloudflare Pages / Netlify / GitHub Pages 等）已生效，**尚未落到生产主站**；恢复需要服务器侧可达（腾讯云 CVM 控制台开机 / 修复 nginx，并把新的公钥写回 `authorized_keys`，再更新 `DEPLOY_SSH_KEY` secret）。
