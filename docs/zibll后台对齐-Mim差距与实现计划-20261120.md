## 3. Mim 侧落地计划（按依赖排序，四批）

### 批次 1：站点通用特性（对应 Global & Features 缺项）
- 新增 `site_settings` 表 + `GET|PUT /site/features`（`appearance:write`）：悬浮按钮、社交分享、自定义 CSS/JS、SEO meta、SMTP 连接参数
- 后台新增「站点特性」面板（与 `Appearance` 并列），逐项开关 + 预览
- 自定义代码注入按 CSP 哈希机制走构建产物（`scripts/csp-inline-hash.mjs`），不接受裸 `<script>`

### 批次 2：权限可视化（对应 Features & Permissions 全部）
- 把 `middleware.ts` 里 `AUTH_REQUIRED_READ_PATHS` / `ANONYMOUS_WRITE_EXCEPTIONS` 从常量迁到 `settings` 表，后台可编辑，默认值保持现状
- 加"匿名可读 / 需登录"预设模板 + 影响面提示；上线前必须用 `scripts/verify-auth-gate.mjs` 复跑（当前 147/147）

### 批次 3：通知与触达（Notifications / WeChat / SMS）
- 统一 `notifications` 偏好表（站内 / 邮件 / 短信三通道，按事件类型勾选）
- 邮件走 SMTP 适配器，短信走可插拔 provider 接口（默认 null provider，不引入付费依赖）

### 批次 4：增强与扩展（IP 归属地 / 内容审核 / 站点安全 / 页面级配置）
- IP 归属地：本地 MMDB 查询，不依赖外部 API
- 内容审核：保留人工队列为主，接一个可插拔审核 provider 接口
- 页面级配置：版块首页、帖子页、列表缩略图字段，落成 `PageBuilder` 的可选项
