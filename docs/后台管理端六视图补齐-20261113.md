# 后台管理端六个业务入口补齐（2026-11-13）

> 基线：`main` @ `9adf6d3`（V0.0.9）→ 本轮版本 `0.0.10`。范围：只补 `apps/admin` 前端入口与少量 CI 配置透传，不改后端业务逻辑、不改数据库结构。

## 1. 为什么补这六个入口

后端在 V0.0.9 已具备以下端点，但管理端没有对应页面，运营只能手调接口，属于「代码已上线、入口未闭环」：

| 能力 | 后端端点 | 权限 |
| --- | --- | --- |
| 批量改价 | `POST/GET /admin/commerce/price-batches`、`POST /admin/commerce/price-batches/:id/rollback` | `commerce:write` |
| 邀请码 | `POST/GET /admin/invites`、`GET /admin/invites/redemptions`、`PATCH /admin/invites/:code/disable` | `rbac:write` / `user:read` |
| 实名审核 | `GET /admin/realname/queue`、`POST /admin/realname/:id/review` | `user:read` / `rbac:write` |
| 内容运营 | `/admin/content/{announcements,changelog,promotions}` | `appearance:write` |
| 自研工具 | `GET /tools/manage`、`POST /tools`、`PUT/DELETE /tools/:slug` | `appearance:write` |
| 社区运营 | 待审板块、首页指向、审核开关、推荐权重、板块 Tab | `appearance:write` |

## 2. 新增页面

| 文件 | 能力 |
| --- | --- |
| `apps/admin/src/views/PriceBatches.tsx` | 目标（模块 / 商品）、模式（固定价 / 百分比 / 金额）、方向、筛选（区域 / 分类 / 编码 / 含下架）；金额按元输入、按分提交；批次快照逐条展示；一键按快照回滚 |
| `apps/admin/src/views/Invites.tsx` | 1–100 批量生成、次数 / 有效期 / 备注；统计卡片；列表禁用；明文码一键复制；核销记录按码过滤 |
| `apps/admin/src/views/Realname.tsx` | 脱敏队列（姓名掩码 + 证件后四位）；通过 / 驳回；驳回原因必填；无权限时明确提示 |
| `apps/admin/src/views/ContentOps.tsx` | 公告 / 更新日志 / 推广计划三页签；创建、发布、归档、暂停 / 启用、删除；版本变更逐行录入；预算元转分 |
| `apps/admin/src/views/ToolsAdmin.tsx` | 工具创建 / 编辑 / 删除；版本记录四段式文本解析；标签、下载、文档、状态与排序；草稿与归档保留 |
| `apps/admin/src/views/CommunityAdmin.tsx` | 待审板块通过 / 驳回；论坛设为首页；建板块审核开关；推荐指数五因子权重；板块 Tab 全量 JSON 配置读写 |

## 3. 壳层接线

- `apps/admin/src/App.tsx`：`ViewKey` 由 7 个扩为 13 个；`NAV` 新增 6 项，权限口径与后端一致；`renderView` 增加 6 个分支。
- `apps/admin/src/api.ts`：新增批量改价、邀请码、实名、内容运营、自研工具、社区运营的类型与方法；全部复用既有 `request()`（凭证注入、扁平错误信封、幂等头）。
- 所有写按钮在 `permissions` 不含对应权限码时禁用，并给出原因提示；查询失败统一 `describeError`，不白屏。
