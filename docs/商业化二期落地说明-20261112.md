# 商业化二期落地说明（2026-11-12）

> 版本：V0.0.5-preview。覆盖付费资产、支付通道、物流售后、提现分成、外观页面搭建、用户成长 / 私信 / IP 归属地、机器翻译与前后台语言分离。所有未配置的第三方供应商都返回明确错误或走手动 / 沙箱，不假装可用。

## 1. 数据模型

全部追加在 `services/mim-api/src/schema.sql`，`CREATE TABLE IF NOT EXISTS`，生产重启即幂等建表：

| 表 | 用途 | 关键约束 |
|---|---|---|
| `paid_assets` | 付费阅读 / 下载 / 图库 / 视频 | `code` 唯一，`kind` 四类，`price_cents`，`vip_free` |
| `asset_purchases` | 资产购买 | `(user_id, asset_id)` 唯一，防重复扣款 |
| `payment_intents` | 支付意图 | `purpose`、`provider`、`amount_cents`、`status`、`pay_url / qr_text` |
| `payment_events` | 回调 / 状态事件 | 幂等履约留痕 |
| `shipments` | 运单与轨迹 | `order_id` 唯一，`events_json` |
| `after_sales` | 售后退款 / 退货 | 仅已付款 / 已发货可申请，金额取实付 |
| `product_reviews` | 商品评价 | `order_id` 唯一，1–5 星 |
| `withdrawals` | 提现申请 | 先冻结余额，人工审核 |
| `creator_earnings` | 创作分成 | 作者 70%，`pending → settled` 条件更新 |
| `site_settings` | 主题 / 语言 / 站点设置 | JSON 值，白名单键 |
| `page_blocks` | 页面区块 | `page + sort_order`，可启停 |
| `badges` / `user_badges` | 徽章与发放 | 编码唯一，`INSERT OR IGNORE` |
| `direct_messages` | 站内私信 | 按 Mim ID 找人，未读 / 已读 |
| `user_signals` | IP 归属地 | 只存 SHA-256 哈希 + 粗粒度国家码 |
| `translation_cache` | 翻译缓存 | `source_hash + target_lang` 去重 |

种子：5 个付费资产（`paid-article-store` / `paid-download-kit` / `paid-gallery-covers` / `paid-video-comic` / `open-source-tools`）、5 个徽章（`newcomer` / `checkin-7` / `first-order` / `creator` / `vip`）、3 项设置（`theme` / `locales` / `site`）、5 个页面区块（首页 3 + 论坛 1 + 商城 1）。

## 2. 接口清单

### 付费资产
- `GET /api/v1/assets?kind=&q=`：列表，返回当前用户 `unlocked`
- `GET /api/v1/assets/:code`：详情；未解锁只回 220 字试读且 `file_url=null`
- `POST /api/v1/assets/:code/purchase`：余额购买；免费 / VIP 免费 / 已购直接成功
- `GET /api/v1/assets/mine/list`：我的已购
- `POST /api/v1/assets`：作者发布（`commerce:write` 非必需，登录即可）

### 支付
- `GET /api/v1/payments/channels`：四渠道配置状态，不回密钥
- `POST /api/v1/payments/intents`：创建支付意图，金额服务端计算
- `GET /api/v1/payments/intents/:id`、`POST /api/v1/payments/intents/:id/cancel`
- `POST /api/v1/payments/intents/:id/offline-confirm`：人工转账确认（`commerce:write`）
- `POST /api/v1/payments/sandbox/notify`：沙箱 HMAC-SHA256 验签，仅 `MIM_PAYMENT_SANDBOX=1`
- `GET /api/v1/payments/admin/summary`：待处理 / 已支付 / 最近支付单

### 履约
- `POST /api/v1/shop/orders/:id/ship`：发货（`commerce:write`）
- `GET /api/v1/shop/orders/:id/shipment`：本人或运营查轨迹
- `POST /api/v1/shop/orders/:id/after-sales`、`GET /api/v1/after-sales/mine`
- `POST /api/v1/after-sales/:id/review`：运营通过即退款关单
- `POST /api/v1/shop/orders/:id/review`、`GET /api/v1/shop/products/:code/reviews`

### 资金
- `POST /GET /api/v1/wallet/withdrawals`：申请 / 我的提现（最低 10 元）
- `POST /api/v1/withdrawals/:id/review`：`approve / paid / reject`
- `GET /api/v1/earnings`、`POST /api/v1/earnings/settle`
- `GET /api/v1/admin/finance/summary`

### 外观
- `GET /api/v1/appearance`：设置与页面清单
- `PUT /api/v1/appearance/settings`：`theme / locales / site` 白名单
- `GET /POST /PUT /DELETE /api/v1/pages/:page/blocks*`
- `PUT /api/v1/pages/:page/reorder`

### 成长 / 私信 / IP
- `GET /api/v1/me/growth`、`POST /api/v1/me/growth/sync`
- `GET /api/v1/levels`
- `GET /POST /api/v1/messages`、`POST /api/v1/messages/:id/read`
- `GET /api/v1/me/ip`

### 国际化
- `GET /PUT /api/v1/i18n/settings`：前后台语言分离
- `POST /api/v1/i18n/translate`：百度翻译适配 + 缓存；未配置 503 `PROVIDER_NOT_CONFIGURED`

## 3. 权限与鉴权

新增权限点：

- `commerce:write`：发货、售后审核、提现审核、支付离线确认
- `appearance:write`：外观设置、页面区块、语言设置

两者均加入 `operator` 基线。运营端点只挂 `requirePermission`（同时支持 Bearer 与 `x-admin-token`），避免前置 `requireAuth` 把引导令牌拦成 401；幂等中间件对引导令牌使用固定作用域 `admin-bootstrap`。

## 4. 环境变量

| 变量 | 用途 |
|---|---|
| `MIM_ALIPAY_APP_ID` / `MIM_ALIPAY_PRIVATE_KEY` / `MIM_ALIPAY_NOTIFY_URL` | 支付宝当面付 |
| `MIM_WECHAT_MCH_ID` / `MIM_WECHAT_API_V3_KEY` / `MIM_WECHAT_SERIAL_NO` / `MIM_WECHAT_PRIVATE_KEY` | 微信 Native |
| `MIM_MANUAL_PAY_ACCOUNT` | 人工转账收款说明 |
| `MIM_PAYMENT_SANDBOX` / `MIM_PAYMENT_SANDBOX_SECRET` | 沙箱支付 |
| `MIM_BAIDU_TRANSLATE_APPID` / `MIM_BAIDU_TRANSLATE_KEY` | 百度翻译 |
| `MIM_IP_HASH_SALT` | IP 哈希盐，缺省回落 `jwtSecret` |
| `MIM_KUAIDI100_CUSTOMER` / `MIM_KUAIDI100_KEY` | 快递100 实时查询；未配置时只返回本地轨迹 |

## 6. 未接与边界

- 支付：虎皮椒 / 讯虎 / PayPal / Stripe 未接；微信 Native 缺证书时明确 `PROVIDER_NOT_CONFIGURED`；支付宝真实下单需商户凭证，当前仅本地逻辑与沙箱验签覆盖。
- 物流：`GET /shop/orders/:id/shipment` 在配置 `MIM_KUAIDI100_CUSTOMER / KEY` 时附带快递100实时轨迹（MD5 签名、8 秒超时、按时间倒序、state 归一化）；未配置或查询失败时 `live.provider=none` / `live.error` 明确标注，仍返回本地登记轨迹，不伪造物流状态。
- 安全：图片 / 滑动 / 腾讯 / 极验验证码、百度内容审核、代理登录、Facebook / Microsoft / Twitter / 百度 OAuth 未接。
- 运维：Redis、CDN、慢查询巡检未接；当前 SQLite + 索引。
- 资金合规：提现必须实名、风控、对账与人工审核；余额不可做成可自由转账的通用支付账户；付费内容需版权授权。
