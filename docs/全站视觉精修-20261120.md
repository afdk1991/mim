# 全站视觉精修（2026-11-20）

本轮目标：对 `apps/web` 全部前端视图做一次真实的 UI / 排版 / CSS 升级，并把上一轮「彩色叠加层」的随机多色收编为一套可维护的品牌色系；不改任何业务接口、不改路由、不改门禁口径。

## 1. 落点

| 文件 | 变更 |
|---|---|
| `apps/web/src/styles-polish.css` | **新增**视觉精修层，约 1.4k 行，逐行中文说明，满足 `comment-check --strict` |
| `apps/web/src/main.tsx` | 在 `styles-colorful.css` **之后**引入精修层，保证层叠顺序最后生效 |
| `apps/web/src/views/Home.tsx` | 首页信息层级重排：eyebrow 标签、双行动按钮、指标条、入口卡图标与箭头、精选区「查看全部」 |

## 2. 设计令牌（`:root` 覆盖）

- 字体：`Inter / HarmonyOS Sans SC / PingFang SC` 可变无衬线栈，中文不再走系统默认宋黑混排。
- 字号阶梯：`12.5 / 13.5 / 15 / 16.5 / 20 / 26 / 34`，正文行高 1.62、标题行高 1.22。
- 圆角：`6 / 10 / 14 / 20`，卡片统一 16px，控件 10px，胶囊 999px。
- 阴影：四档冷调投影 + 一层品牌色环境光，替代原来的灰雾阴影。
- 表面色：页面底 `#f4f6fa` 与白卡之间保留一档色相差，仍用 `color-mix()` 继承板块色相，不写死浅色值。
- 品牌渐变：`--pd-grad` = 靛蓝 `#4f46e5` → 湖蓝 `#2f7cf6` → 青绿 `#0d9488`，替代七彩与蓝紫粉混色。

## 3. 首页重排

- `home-hero` 由浅色大卡改为深色渐变主视觉（双光斑 + 装饰环 + 品牌渐变标题），配 eyebrow、两个行动按钮与三项结构指标（3 核心入口 / 0 阅读门槛 / 8 页面视图，均为真实结构数据）。
- 入口卡：新增线性 SVG 图标块、右上箭头，悬停上浮 + 渐变描边。
- 精选帖：标题行改为左侧渐变竖条 + 右侧「查看全部」，卡片悬停抬升，元信息与统计用等宽数字。

## 4. 彩色层收编

- 标题：页面主标题保留品牌三段渐变，其余 `h2/h3/h4` 回归实色，靠字重与字号拉层级。
- chips / badge / tag：取消 9 档与 6 档 `nth-child` 随机配色，统一中性药丸；语义色只留给价格、锁定、状态。
- 卡片：左侧色条统一为 3px 品牌渐变；元信息取消三色轮换；悬停标题由整段渐变改为主色。
- 列表 / 表格：去掉奇偶彩色渐变与表头三色底，改为细线分界 + 悬停淡底。
- 正文装饰：取消红色首字下沉、红色 `strong`、紫色 `em`、青绿 `code`。
- 保留的彩色语义：板块 `data-theme-section` 色相（论坛蓝 / 图库紫 / 视频玫红 / 公告橙 / VIP 金 / 钱包青绿 / 商城洋红 / 推广青）与榜单名次金银铜。

## 5. 其他视图

- 登录页：两栏重排，引导标题渐变、分段控件改胶囊外壳、登录卡 22px 圆角 + 大阴影、三块说明同宽对齐、取消整屏最小高度造成的半屏空带。
- 通用组件：面板 16px 圆角 + 细描边、按钮胶囊化（主按钮渐变、次按钮白底描边）、输入框 44px 热区 + 主色焦点环、侧栏挂件统一卡面与渐变标题条、页脚与移动端 Tab 统一玻璃底。
- 暗色：精修层全部给出 `[data-theme='dark']` 分支；修复 `.card / .block` 规则误伤 `.btn.block`（导致侧栏主按钮在暗色下丢失渐变）的问题，改为 `:not(.btn)`。
