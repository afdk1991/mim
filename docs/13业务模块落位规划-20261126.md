## 一、现有模块与路由梳理（实测口径）

### 1.1 前端 SPA（`apps/web`，生产 `https://zy.laal.top`）

对外路径段由 `apps/web/src/router.ts` 的 `VIEW_SEGMENTS` 一处定义，共 10 个：

| 路径段 | 视图 | 匿名可读 | 说明 |
|---|---|---|---|
| `/home` | Home | 是 | 门户首页 |
| `/community` | Community（含子目录组件） | 是 | 社区 / 公告 / 付费阅读 / 钱包 / 商城 / 推广 |
| `/circles` | Circles | 是 | 成员制圈子 |
| `/chat` | Chat | 否 | IM 与视频通话 |
| `/account` | Profile | 否 | 个人中心与账号设置 |
| `/checkout` | Checkout | 否 | 收银台 |
| `/pay-return` | PaymentReturn | 是 | 支付回跳三态结果 |
| `/legal/<kind>` | Legal | 是 | privacy / terms / refund / help 四篇 |
| `/signin` | Login | 是 | 登录 |
| 未知路径 | NotFound | 是 | 独立 404 |

> 说明：`/domains`、`/pricing` 两个段在 HEAD 中存在，但当前工作区已被并行改动删除，本轮不依赖、不恢复。

### 1.2 后端 API（`services/mim-api`，生产 `https://api.laal.top/api/v1`）

已有路由模块（`services/mim-api/src/routes/`）按域划分，与本任务相关的公开只读能力：

| 能力 | 路由模块 | 本轮用途 |
|---|---|---|
| 健康探针 | 内建于 `app.ts`（`/health`、`/api/v1/healthz`） | 静态页异步探活 |
| 社区动态 | `routes/community.ts`（`GET /community/trending`、`/community/threads`、`/community/tags` 等） | 静态页异步补充 |
| 站点选项 | `routes/site-options.ts`（公开字段只读） | 未使用（避免与在途改动耦合） |
| 支付 / 钱包 / 订单 | `payments.ts` / `orders.ts` / `me.ts` | 仅做跳转入口，不直连 |
| 内容 / 申诉 / 实名 | `content-ops.ts` / `appeals.ts` / `realname.ts` | 仅做入口映射 |

### 1.3 静态文档站（`site/`）

`site/index.html`（站点首页）+ `site/prd.html`（产品文档），零依赖、逐行注释、深色设计令牌。本轮新增内容挂在同目录下的 `site/domains/`。

### 1.4 管理后台（`apps/admin`）

独立静态根（生产 `/admin/`），承载概览、发货售后、改价、邀请码、实名审核、内容运营、社区运营、页面搭建、角色权限、用户等视图。本任务不改后台。

## 三、实现内容

### 3.1 交付文件清单

| 类别 | 文件 | 说明 |
|---|---|---|
| 内容数据源 | `site/domains/domains.data.json` | 13 领域内容的单一出处；slug / 名称 / 分组 / 状态 / 简述 / 复用 / 功能点名与 `catalog.ts` 逐字对齐 |
| 生成器 | `scripts/build-site-domains.mjs` | 零依赖生成详情页、索引页、sitemap、robots；数量与 slug 唯一性校验 |
| 共享样式 | `site/domains/domains.css` | 与 `site/index.html` 同一套设计令牌；13 页共用一份 |
| 动态增强 | `site/domains/live.js` | 异步探活 + 拉取社区动态；超时 / 跨域 / 非 2xx 全部降级，不抛错 |
| 静态产物 | `site/domains/*.html`（14 个）、`site/sitemap.xml`、`site/robots.txt` | 生成后入库，静态托管直接可用 |
| 本文档 | `docs/13业务模块落位规划-20261126.md` | 落位规划与交付说明 |

### 3.2 动静结合的具体做法

- **静态**：每页 HTML 内含标题、导语、3 个场景、4 个功能点、4 步流程、复用映射表、3 条 FAQ，以及三组 JSON-LD（BreadcrumbList / WebPage / FAQPage）。禁用 JS 仍完整可读。
- **动态**：`live.js` 先请求 `/api/v1/health` 判断服务在线，再请求 `/api/v1/community/trending` 取最多 3 条动态；渲染只用 `createElement` + `textContent`，不使用 `innerHTML`，避免注入。
- **降级**：超时 3 秒、跨域未授权、非 2xx、结构不符，统一把状态条改成「实时数据暂不可用（静态内容不受影响）」，不产生控制台异常、不影响其余内容。

### 3.3 性能与安全

| 维度 | 做法 |
|---|---|
| 请求数 | 每页 1 个 CSS + 1 个 defer JS；图标为内联 SVG，零图片、零外部字体 |
| 首屏 | 内容全在 HTML 内，无接口等待；CSS 单文件约 13KB 可缓存 |
| SEO | title / description / keywords / canonical / robots / OG / Twitter / 三组 JSON-LD / sitemap / robots.txt |
| 安全 | 全量 HTML 转义；JSON-LD 转义 `<`；无内联事件处理器；无第三方脚本；动态渲染不用 `innerHTML` |
| 可访问性 | 跳过导航、语义化 landmark、`aria-current`、原生 `details` 折叠、键盘焦点样式 |
| 响应式 | 900px / 640px 两级断点，窄屏单列，无横向溢出 |

## 五、发布与回退

### 5.1 发布前提

- 生成器默认 `SITE_BASE_URL=https://zy.laal.top`，用于 canonical 与 sitemap 的绝对地址；换域名时用环境变量覆盖后重新生成即可。
- 本轮产物只在仓库内，**尚未接入任何生产静态根**；要对外可访问，需要把 `site/domains/`、`site/sitemap.xml`、`site/robots.txt` 复制到实际静态目录（由部署链路负责人决定落点）。

### 5.2 回退

- 全部为本轮新增文件，回退即删除：`site/domains/`（整个目录）、`site/sitemap.xml`、`site/robots.txt`、`scripts/build-site-domains.mjs`、本文档。
- 不涉及数据库、不涉及既有页面、不涉及运行时配置，回退无连带影响。
