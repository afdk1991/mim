## 2. 后端工具路由

### 2.1 工厂与挂载

- 工厂名：**`createToolsRouter(deps: ApiDeps): Router`**（`services/mim-api/src/routes/tools.ts`）。
- 挂载口径：与其余域一致，由主控 `createApp` 注入 `resolved` 依赖后 `app.use('/api/v1', createToolsRouter(resolved))`。当前 `app.ts` 第 144 行已由主控接入；本包未改动 `app.ts`。
- 权限：公开浏览免鉴权；管理端清单与增删改复用既有权限码 **`appearance:write`**（未新增 RBAC 种子，避免触碰 `db.ts`）；写操作挂 `idempotency` 幂等中间件。

### 2.2 路由契约

| 方法 | 路径 | 鉴权 | 说明 |
| --- | --- | --- | --- |
| GET | `/api/v1/tools` | 公开 | 上线清单，支持 `?q=` 关键词、`?tag=` 标签；按 `sort_order ASC, created_at DESC` |
| GET | `/api/v1/tools/manage` | `appearance:write` | 全状态清单（含草稿 / 归档），支持 `?status=` |
| GET | `/api/v1/tools/:slug` | 公开 | 详情；草稿 / 归档 / 不存在一律 404，不泄露存在性 |
| POST | `/api/v1/tools` | `appearance:write` | 新建；slug 冲突 409；非法入参 400 |
| PUT | `/api/v1/tools/:slug` | `appearance:write` | 更新；slug 不可改以免外链失效；版本记录 / 标签整体覆盖 |
| DELETE | `/api/v1/tools/:slug` | `appearance:write` | 删除；不存在 404 |

响应字段：`id, slug, name, summary, version_notes[], download_url, doc_url, tags[], status, sort_order, created_at, updated_at`。`version_notes` 条目：`{ version, title?, notes?, released_at? }`。脏 JSON 读取回落空数组，不拖垮列表。

### 2.3 Schema 与种子

- `21-tools.sql`：`mim_tools` 表（`slug` 唯一、`status CHECK draft/active/archived`、`sort_order`）+ `idx_mim_tools_public` 索引；全部 `CREATE TABLE IF NOT EXISTS` / `CREATE INDEX IF NOT EXISTS` / `INSERT OR IGNORE`，无 DROP / DELETE / 无条件 UPDATE。
- 三条幂等种子（按 slug 幂等，重复启动不覆盖运营已编辑内容）：

| slug | 名称 | 标签 | 版本 |
| --- | --- | --- | --- |
| `quick-build-wp` | Quick Build WP | wordpress / 建站 / 插件 | 1.0.0 |
| `db-replace-domain` | 数据库批量替换 / 换域名插件 | database / wordpress / 迁移 | 2.1.0 |
| `liudun-waf` | 流盾 WAF | waf / 安全 / 防护 | 0.9.2 |

- `20-appearance.sql`：补 `page_blocks(page, enabled, sort_order)` 索引；`INSERT OR IGNORE` 兜底默认主题（主色 `#0f766e`、底色 `#f8fafc`、圆角 14、字体 system-ui）与站点信息，缺配置时前台回落默认外观。

## 3. 前端消费链路

### 3.1 主题 / 配色 / 圆角 / 字体（CSS 变量注入）

`App` 启动拉取公开 `GET /site/config` → `resolveTheme()` 逐项清洗（HEX 校验、圆角 0–32、列表样式白名单、导航项过滤）→ `applyThemeVars()` 写入 `:root`：`--primary`、`--primary-dark`、`--bg`、`--radius`、`--font-family`，并在 `<html>` 挂 `data-list-style` / `data-nav-layout`。接口不可达或脏数据逐项回落 `DEFAULT_THEME`，首帧不白屏。

### 3.2 导航项读配置

内置导航为白名单真源；`theme.nav_items` 按 `view` 覆盖文案 / 显隐，未知视图忽略，未覆盖的内置项原样保留。

### 3.3 列表样式 card / list / compact

`data-list-style` 透传到布局根，CSS 变体真实影响商城 `.cards`、统一入口 `.cards`、论坛 `.community-list`、工具 `.tools-grid`、推广 `.promotions-grid`：`list` 单列行式，`compact` 收紧间距与内边距；`card` 为默认网格。

### 3.4 页面区块按 order 渲染

`PageBlocks` 拉取 `GET /appearance/pages/:page`，前端再按 `sort_order` 升序兜底；支持 `hero / features / tabs / notice / announcements / announcement / button / image_text / product_grid`；接口失败或空清单返回空态，不阻断整页。

### 3.5 论坛设为首页

根路径解析顺序：`GET /community/home-setting`（冻结契约 `{ home: 'community' | 'portal' }`）→ 404 / 异常回落 `GET /site/config` 的 `home_view` → 再失败保持门户现状。深链接与站内导航不拦截。

### 3.6 板块 Tab 模块化

切换板块时拉取 `GET /community/boards/:slug/tabs`；归一化兼容 `sort_order/sort_by` 与冻结契约 `order/sort` 两套字段名；按 `order` 升序、仅渲染 `visible` 项，点击把 `sort_by` 对齐到帖子列表 `sort` 参数。版主（`is_moderator`）可切换栏目显隐并 `PUT /community/boards/:slug/tabs` 保存。接口缺失 / 404 回落内置默认 5 个 Tab（最新 / 热门 / 推荐指数 / 评分 / 收藏）。

### 3.7 列表排序入口

论坛排序在最新 / 热门 / 浏览 / 回帖 / 收藏 / 评分之外补 **推荐指数（`recommend`）**，与后端 `SORT_BY_KEYS` 对齐；评分、收藏入口保留。

### 3.8 公告 / 更新日志 / 推广计划

- 公告：`AnnouncementBar` 置顶条（最多 3 条置顶）+ `ContentHub` 公告列表（置顶徽标、发布日期）。
- 更新日志：`ContentHub` 时间线（版本号节点 + 标题 + 正文 + 日期）。
- 推广计划：卡片网格（名称、简介、有效期、状态、落地链接）。
- 三个接口独立 `Promise.allSettled`，任一 404 或空数组静默隐藏对应栏目，不报错。

### 3.9 自研工具发布页

公开清单 / 详情（版本记录时间线、下载 / 文档链接、标签）；已登录运营在页内管理面板新建 / 编辑 / 删除，草稿仅管理端可见。

### 3.10 性能：路由级懒加载

15 个重型视图经 `React.lazy` + 动态 `import()` 拆为独立 chunk，`Suspense` 统一占位；登录页与公告条保持 eager。新增区块配图 `loading="lazy"`。

## 9. 验证码三形态前端闭环

### 9.1 链路

1. 挂载后拉取 `GET /api/v1/security/status`（公开免鉴权），读取 `captcha.mode`（`off | image | slider | tencent | geetest4`）、`captcha_required`、`required_scenes`、`providers`。
2. 按场景签发：注册模式 `scene=register`，其余 `scene=login`；`GET /api/v1/auth/captcha?scene=` 返回图形 `svg` 或滑块题目（`id` + `slider.background` / `slider.gap{y,width,height}`）。
3. 提交登录 / 注册 / 注册发码时，按当前形态把票据字段随请求体带上；`mode=off` 不带任何验证码字段，不打断 0.0.9 现网登录。
4. tencent / geetest4 在对应 provider 未配置凭证（`providers.tencent` / `providers.geetest4=false`）时前端只渲染「组件待加载」占位且不报错；不引入未配置的第三方 SDK 脚本。

### 9.2 前端票据 ↔ 后端校验字段对照

| mode | 签发接口 | 前端随请求体字段 | 后端 `verifyCaptcha` 读取字段（`security.ts`） | 未配置 / 回落 |
| --- | --- | --- | --- | --- |
| `off` | 不签发 | 不带验证码字段 | 直接放行 | 零影响 |
| `image` | `GET /auth/captcha?scene=` → `id`, `svg` | `captcha_id`, `captcha_code` | `captcha_id`（别名 `id`）、`captcha_code`（别名 `answer`） | 内置形态 |
| `slider` | 同上 → `id`, `slider{background,gap}` | `captcha_id`, `slider_x`（数字，拼图块 x 坐标） | `captcha_id`（别名 `id`）、`slider_x` | 内置形态；后端容差 ±12px |
| `tencent` | 同上（第三方缺凭证后端 503） | `ticket`, `randstr` | `ticket`, `randstr` | `providers.tencent=false` 时隐藏占位，不报错 |
| `geetest4` | 同上 | `lot_number`, `captcha_output`, `pass_token`, `gen_time` | `lot_number`, `captcha_output`, `pass_token`, `gen_time` | `providers.geetest4=false` 时隐藏占位，不报错 |

> 接线说明：`security.ts` 适配器已实现上述票据校验；`auth.ts` 的 password / register / login 路由当前尚未在服务端调用 `verifyCaptcha`，前端已按契约把票据字段随请求体带上，后端接线后即生效。滑块拖拽坐标与第三方 SDK 真机回调未在有后端 / 有 key 的环境做运行时联调（见 13. 遗留）。

## 10. 商城结算积分抵扣 UI

### 10.1 数据来源与展示口径

- 余额 / 积分：`GET /wallet` → `wallet.points`。
- 抵扣口径：`GET /site/config` → `points_deduction: { enabled, points_per_yuan, max_ratio_percent }`；口径缺失回落默认（开启、100 积分 = 1 元、单笔上限 30%）。
- 面板展示条件：`enabled && points_balance > 0 && 应付 > 0`；勾选默认 **不** 选。
- 预览口径（前端纯计算，单位：分 / 积分）：
  - 余额可折金额 `byBalanceCents = floor(balance / points_per_yuan * 100)`；
  - 比例上限 `byRatioCents = floor(totalMinor * max_ratio_percent / 100)`；
  - 本次抵扣 `deduct = min(byBalanceCents, byRatioCents, totalMinor)`；
  - 消耗积分 `points_spent = ceil(deduct / 100 * points_per_yuan)`；
  - 应付 `payable = totalMinor - deduct`。

### 10.2 提交字段对照

| 端 | 接口 | 入参字段 | 说明 |
| --- | --- | --- | --- |
| 前端购物车结算 | `POST /cart/checkout` | `channel`（`manual`）、`use_points`（勾选且面板可用时 `true`） | 后端另支持可选 `points_to_use`（指定抵扣积分数）；本轮前端按布尔开关传 `use_points`，`use_points=true || points_to_use!==undefined` 即视为使用积分；结算结果回 `points_spent` / `points_deduct_cents` / `payable_cents` |
| 前端独立商城下单 | `POST /shop/orders` | `product_code`, `quantity`, `coupon_code`, `shipping` | **该契约无积分字段**；弹窗仅展示只读余额 / 积分提示，不发抵扣入参 |

> 偏差说明：独立商城（shop）下单链路当前不支持积分抵扣，属后端契约缺口；前端未伪造入参。抵扣总开关关闭时购物车整块隐藏。
