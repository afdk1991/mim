## 0. 适用与否的总结论

| 部署形态 | 是否涉及 | 说明 |
| --- | --- | --- |
| GitHub Pages（`*.github.io` 域名） | 涉及 | 境外托管、由 GitHub 提供域名，**无法做 ICP 备案**；如面向中国大陆用户提供服务存在访问与合规不确定性 |
| 自托管服务器（自有域名 + 公网 IP） | 涉及 | 一旦绑定中国大陆境内服务器并使用自有域名，**ICP 备案为强制项**；当前仓库未配置真实域名 |
| 微信小程序 | 未上线 | 无小程序工程目录（已核实），若上线则需小程序备案 + 类目资质 |
| Android APK（GitHub Release 分发） | 涉及 | 通过 Release 附件分发（`scripts/gen-ota-manifest.mjs` 生成的 manifest 指向 `github.com/<repo>/releases/download/...`），**未上架应用商店**，因此不受商店审核约束；但《移动互联网应用程序信息服务管理规定》下的 **App 备案**在境内分发场景需评估 |
| iOS / 鸿蒙 | 未上架 | 有壳工程（`ios/`、`harmony/`），未上架，暂无商店审核义务 |
