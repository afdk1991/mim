# 站点选项后台（Global & Features 落地）— 2026-11-20

## 1. 这件事的边界

用户给出的参照地址是 `https://laal.top/wp-admin/admin.php?page=zibll_options#tab=global-features`。该地址属于 `laal.top` 上的 WordPress + Zibll 主题（站点名「laal 社区」），按项目口径**不是 Mim、禁止改动**。因此本轮做的事情是：**把它当功能参照面，在 Mim 里实现同等后台能力**，不对那套 WordPress 做任何写操作（全程只读浏览，未提交任何表单）。

## 2. 参照面实读结果

`Global & Features` 页签下有 10 个分组：Logo image、SEO、Common features（Display & Layout / Search / Mobile Bottom Tab Bar / Floating Buttons / Multilingual Translation / Social sharing / Email / Custom code）。本轮把其中**能用真实能力兑现的部分全部落地为可读写配置**，而不是做成只存不用的表单。

## 3. Mim 实现（V0.0.16-preview）

### 3.1 声明式注册表
`services/mim-api/src/options/registry.ts`

- 结构：`OptionTab → OptionGroup → OptionField`，字段声明含 `key / label / type / defaultValue / hint / options / min / max / publicRead / secretPlaceholder`。
- 覆盖 10 个分组、40 个字段，默认值一律等于**现行行为**，因此未配置时前台表现与升级前一致。
- 模块加载即自检：键重复、类型非法、下拉缺候选项、数值默认值非数字，直接抛错，避免坏声明渲染出坏控件。
- 清洗：布尔只认布尔、数值夹到声明区间、下拉不在候选内回落默认、文本按类型截长度上限；未知键直接丢弃。

### 3.2 接口
`services/mim-api/src/routes/site-options.ts`

| 方法 | 路径 | 鉴权 | 说明 |
|---|---|---|---|
| GET | `/api/v1/site/options` | 匿名可读 | 只返回 `publicRead` 字段，邮件分组不外泄 |
| GET | `/api/v1/admin/site-options` | `appearance:write` | 返回 schema + 完整取值 + 最后保存时间 |
| PUT | `/api/v1/admin/site-options` | `appearance:write` | 局部写入，只提交改动键，返回 `changed` 清单 |
| POST | `/api/v1/admin/site-options/reset` | `appearance:write` | `keys` 缺省为全量恢复默认 |

存储：`site_settings` 表单条 JSON（`key = options`），与既有 `theme` / `site` / `home` / `pages` 并存互不覆盖。

### 3.3 后台面板
`apps/admin/src/views/SiteOptions.tsx` + `apps/admin/src/api-site-options.ts`

- 完全按后端 schema 数据驱动，新增字段只改注册表，视图零改动。
- 分组卡片 + 逐字段控件；顶部显示「最后保存时间 / 待保存 N 项」，只提交差异。
- 分组级「恢复默认」与「全部恢复默认」都走同一个 reset 端点。
- 导航新增独立「站点选项」，**不写进**并行在途的 `Settings.tsx`，避免互相覆盖。

### 3.4 前台真实消费
`apps/web/src/site-options.ts` + `apps/web/src/FloatingActions.tsx`，以及 `Shell.tsx` / `App.tsx` / `CommunityMore.tsx` 的接入点：

| 后台字段 | 前台落点 |
|---|---|
| `seo_title` / `seo_description` / `seo_og_image` | `document.title` 与 `meta description` / `og:*` |
| `site_icon_url` / `desktop_icon_url` | `<link rel="icon">` 与 `apple-touch-icon`（148×148） |
| `logo_light_url` / `logo_dark_url` | 头部品牌位按当前明暗替换文字 Logo，缺一侧互相兜底 |
| `layout_width` | `:root --page-max`，外壳与顶栏同宽 |
| `show_right_sidebar` | `Shell` 的 `showSide`，关掉后桌面端单栏 |
| `show_footer` | 页脚整块不渲染 |
| `sticky_header` | 头部由吸顶退化为静态 |
| `card_radius` | `[data-site-radius]` 覆盖 `--radius-md` |
| `mobile_tab_enabled` / `mobile_tab_items_max` | 底部 Tab 是否渲染与最多项数 |
| `floating_enabled` / `position` / `back_to_top` / `contact` / `contact_url` | 悬浮按钮层的开关、停靠方向、回到顶部与联系入口 |
| `share_enabled` / `share_wechat|weibo|qq|x|copy` | 悬浮层的分享面板渠道（微信与复制走剪贴板） |
| `search_placeholder` / `search_hot_words` | 社区搜索框占位与「热门搜索」词条，点击即搜 |
| `search_default_sort` / `search_diversify_default` | 搜索面板初始排序与去同质状态 |
| `default_locale` | 未登录且账号无语言偏好时的界面语言 |
| `custom_css` | 注入 `<style id="mim-site-custom-css">`，保存后前端下一请求周期生效 |

**明确不做**：`custom_js` 这类运行时脚本注入不开放。脚本注入按构建期 CSP 哈希口径（`scripts/csp-inline-hash.mjs`）管理，运行期放开等于自废 CSP。

### 3.5 邮件分组的口径
`smtp_*` 只保存主机 / 端口 / TLS / 账号 / 发信人，**口令不进库**：`smtp_password_ref` 只记录环境变量名（默认 `MIM_SMTP_PASSWORD`）。`mail_enabled` 为总开关，默认关闭。
