# 组织与验收文档索引

本目录把「人员职责 → 模块归属 → 任务清单 → 验收标准」串成一条线，回答三个问题：**这块谁负责 / 现在还差什么 / 怎么算做完**。

| 文件 | 用途 | 负责人 |
|---|---|---|
| `00-角色职责与模块归属.md` | 11 个角色对应到真实目录与文件，并给出命名与依赖方向约束 | CTO |
| `01-任务清单与优先级.md` | P0（已闭环）→ P3（明确不做），含依赖关系图 | CTO |
| `02-Phase1交付物验收清单.md` | 按角色的交付物 × 验收标准 × 达成状态， PM 组织验收 | PM + CTO |

## 使用约定

1. **改代码前先看 00**：知道 Owner 才知道该找谁评审；跨模块改动涉及多个 Owner，必须在 PR 里点名。
2. **新增任务看 01**：优先级只允许标 P0~P3，标 P0 必须同时写出「阻塞了谁」。
3. **版本验收看 02**：未达标项必须写原因与补救日期，不接受「完成度高」。
4. **矩阵每季度或每个大版本复审一次**（RACI 使用规则第 4 条），人员变动时同步更新，否则很快变成废纸。
