## 2. 扫描器覆盖的五类断言

`scripts/gap-scan.mjs` 为零依赖纯静态分析，不执行代码、不访问外部服务。

| 断言 | 检查口径 | 数据来源 |
| --- | --- | --- |
| A. 路由装配 | 遍历 `services/mim-api/src/routes/*.ts` 导出的 `create*Router` 工厂，逐个核对在 `src/app.ts` 中是否被 import 且被 `app.use(...)` 或受保护路由 for 循环引用；列出未挂载清单 | `routes/*.ts`、`src/app.ts` |
| B. 表结构接缝 | 逐语句检查 `schema.d/*.sql`：非幂等 `DROP TABLE/INDEX`、`DELETE FROM`、缺 `WHERE` 的 `UPDATE`；校验 `ALTER_ADD:` 指令格式（`表名.列名 定义`）；确认 `services/mim-api/build.mjs` 确实把 `src/schema.d` 搬运到 `dist/schema.d` | `schema.d/*.sql`、`services/mim-api/build.mjs` |
| C. 环境变量登记 | 收集源码（后端 / 前端 / admin / packages / functions / workers / scripts / deploy）出现的全部 `MIM_*`，与 `.env.example` 精确名、09 清单精确名与前缀通配比对；额外检查「代码用了但没登记」方向。脚本 / 部署编排 / 蓝图注册表 / 内部开关类变量降级为 WARN，不计硬缺口 | 源码目录、`.env.example`、09 清单 |
| D. 前端接线 | `apps/web/src/views/*.tsx` 是否在 `App.tsx` 被静态 import 或 lazy 引用；未直接注册但被其它视图 import 的标记为嵌套子组件（WARN）；`router.ts` 的 `VIEW_SEGMENTS` 是否覆盖全部 `AppView` 标识 | `views/*.tsx`、`App.tsx`、`router.ts` |
| E. 未完成标记 | 扫描 `TODO / FIXME / XXX / HACK / 未实现 / 待实现`，逐条给出 `文件:行号`；纯注释行与描述性字符串（状态码说明、边界差距说明）降级为 note，不判硬缺口 | 后端 / 前端 / packages / functions / workers 源码 |

## 5. deploy.sh 新增幂等段

位置：既有「验证码通道（阿里云短信 / AWS SES）」循环之后、文件属主 `chown` 段之前。新增 `ADAPTER_VARS` 列表遍历段，覆盖 §4.2 的 64 个变量。

**幂等语义（逐条）：**

1. 本次 CI 透传**非空** → 覆盖 `$MIM_ENV_FILE` 现有同名行（支持密钥轮换，与 `MIM_AUTH_ADMIN_PASSWORD` 的 CI 路径一致）；文件缺该行则追加；
2. 本次**未透传**（空串）但文件已有值 → **保留运维现值**，绝不覆盖；
3. 文件缺失该项且未透传 → 写入空占位 `NAME=`；
4. 重复执行不产生重复行（已存在的变量走行替换而非追加）；全程日志不回显任何密钥值。
