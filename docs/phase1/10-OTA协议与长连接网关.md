## 1. OTA 协议（proto_v1，与固件版本号解耦——04 号文 §2）

### 1.1 版本登记（后台发布，权限点 `device:ota:publish`）

| 字段 | 说明 |
| --- | --- |
| fw_version / build | `x.y.z+build`，build 单调递增，设备拒绝更低 build（防降级） |
| model | 适用型号列表 |
| url / sha256 / signature | 对象存储固件包 + 摘要 + 签名（防砖原则一：验签不过不刷） |
| mandatory | true 时设备端不可跳过 |
| gray_plan | `5% → 观察 24h → 50% → 100%`（04 号文 §4.4，不可跳档） |

### 1.2 检查更新

`POST /api/v1/devices/{device_id}/ota/check`

```json
{ "fw_version": "1.0.0", "build": 1000, "model": "mim-s1" }
→ 200 { "code": 0, "data": { "update": true, "fw_version": "1.1.0", "build": 1024,
        "url": "https://oss…/fw-1.1.0.bin", "sha256": "…", "signature": "…",
        "mandatory": false, "size_bytes": 8388608 } }
→ 无更新：{ "update": false }；型号不适用：30202
```

### 1.3 设备端状态机与防砖

```
idle → downloading(断点续传) → verifying(sha256+签名) → switching(A/B 分区) → confirming(首启自检) → done
                                  ↓ 失败                ↓ 首启失败              ↓ 超时未确认
                                idle(报原因)          自动回滚旧分区并上报      自动回滚并上报
```

- 上报：`POST /api/v1/devices/{device_id}/ota/report`，`{build, stage, result, fail_reason}`，对应埋点 `ota_success / ota_fail`（06 号文 §5）。
- 防砖三原则（01/04 号文重申）：验签不过不刷、A/B 双分区可回滚、档间观察窗 ≥24h 且成功率 ≥99% 才进下一档。
- 一键暂停：OTA 面板按钮（权限点 `device:ota:pause`）5 分钟内全量停止下发（04 号文 §4.4）。

### 1.4 灰度实现

设备按 `device_id` 哈希分 100 桶；灰度档位=桶阈值 5/50/100；`ota/check` 按当前档位+设备桶判定是否返回更新。档位推进人工确认（不得自动跳档），面板展示成功率与失败原因分布。

## 2. 长连接网关骨架（EMQX，ADR-002 已定）

### 2.1 连接生命周期

```
设备 ──TLS 8883──▶ EMQX ──HTTP 认证钩子──▶ 设备服务（校验 Device-Token，未激活返 401）
连接成功 → 订阅 $dev/{id}/cmd，建立离线会话（QoS1）
断开 → EMQX 事件钩子 → 设备服务更新在线状态 + 影子离线
```

- 认证：一机一密 Device-Token（激活签发，01 号文 §2.1），HTTP auth 对接设备服务，禁匿名。
- Topic：`$dev/{device_id}/cmd`（下行指令）、`/up`（上行状态）、`/shadow`（设备影子，保留消息）。

### 2.2 指令通路（设备控制，06 号文 §3.3.1）

```
App ──HTTPS──▶ 设备服务 ──校验绑定+在线──▶ EMQX publish $dev/{id}/cmd（QoS1）
设备执行 ──▶ $dev/{id}/up 回执 ──▶ 设备服务回写指令状态 → App 轮询/推送
```

- 离线设备：30102；未绑定/被他人绑定：30103。
- 指令端到端目标 P95 < 1s（在线设备）；指令 id 幂等，重发不产生重复动作。

### 2.3 压测口径（M2 验收）

10 万并发连接模拟（压测环境独立集群），指标：连接建立成功率 ≥99.9%、心跳 keepalive 300s 下 CPU/内存水位、单节点故障重连风暴恢复 < 5min。报告入 M2 评审。

## 3. 接口错误码登记（03 号文规范二段位）

| code | 场景 |
| --- | --- |
| 30101 设备不存在 / 30102 设备离线 / 30103 已被他人绑定 | 指令与绑定通路 |
| 30201 OTA 签名校验失败 / 30202 固件版本不适用 | OTA 通路 |

## 4. M2 验收口径（02 号文 S3）

- 设备真机上线/离线/指令闭环；OTA 测试通道全量下发成功、无砖
- 10 万连接压测报告产出；灰度面板可按桶推进与一键暂停
