# PRD v1 套件（06 号文）

> 责任岗位：PM
> 版本：v1.0
> 日期：2026-10-30
> 依据：00 号文前提与假设 A1–A7、02 号文排期、03 号文四规范、04 号文发版契约。本文档只定义「做什么、做到什么程度」，技术方案以 01 号文为准。

## 1. 产品目标（Phase 1 验收口径）

| 目标 | 量化指标（01 号文非功能指标） | 业务指标（发布后 30 天） |
| --- | --- | --- |
| 设备可配可控 | 配网成功率 ≥95%、OTA 成功率 ≥99%、防砖 0 事故 | 激活绑定率 ≥80% |
| 音视频可用 | RTC 接通率 ≥98%、P50 延迟 <400ms | 人均通话时长有基线值 |
| 社区可运营 | UGC 先审后发全链路通 | 发布渗透率 ≥10% DAU |
| 商业闭环通 | 对账差异率 <0.01% T+1 | 付费率有基线值 |

## 2. 用户与核心场景

| 角色 | 场景 |
| --- | --- |
| C 端用户（家庭/个人） | 购机 → 小程序/App 配网绑定 → 远程查看与通话 → 社区分享 → 会员增值 |
| 运营（ops） | 内容审核队列、活动推送、数据看板 |
| 客服（cs） | 用户/设备查询、工单、协助配网失败用户 |
| 审核（auditor） | UGC 先审后发处置 |
| 财务（finance） | 订单查询、对账差异处理、退款审批 |

## 3. 功能需求（按模块，P0=Phase 1 必须，P1=尽量，P2=Phase 2 候选）

## 5. 埋点事件表（遵 03 号文规范四；★ = 已在 03 号文口径字典登记）

| 事件名 | 触发时机 | 关键参数 | 责任端 |
| --- | --- | --- | --- |
| auth_login_click / auth_login_success / auth_login_fail | 登录 | channel(验证码/微信) | 全端 |
| auth_register_success | 注册完成 | channel | 全端 |
| device_bind_start ★ | 进入配网 | model | 小程序/App |
| device_bind_success ★ / device_bind_fail | 配网结果 | fail_reason, retry_count, duration_ms | 小程序/App |
| device_unbind_submit / device_unbind_success | 解绑 | — | App |
| device_control_submit / device_control_success / device_control_fail | 控制指令 | action(重启/音量/摄像头) | 小程序/App |
| ota_check_click / ota_success / ota_fail | 固件升级 | from_ver, to_ver, fail_reason | App + device |
| call_invite ★ / call_connected ★ / call_fail | 呼叫与接通 | callee_type(app/device), quality_grade | App |
| call_cancel | 主叫取消 | before_10s(bool) | App |
| pay_order_submit ★ / pay_success / pay_fail | 支付 | sku, amount(分), channel(iap/wx) | 小程序/App |
| post_submit ★ / post_success / post_fail | 发布动态 | media_type | App |
| post_expose / post_click | 信息流 | feed_tab | 小程序/App |
| post_report_submit | 举报 | reason | 小程序/App |
| push_expose / push_click | 推送到达/点击 | campaign_id | 全端 |

> 所有新事件先登记本表再开发（03 号文规范四硬规则 1）；公共参数（platform/app_version/session_id/request_id 等）全事件必带，不再逐条列出。

## 6. 国内合规清单（P1 不出海前提，逐项落实责任人）

| # | 事项 | 要求 | 责任岗 | 完成时点 |
| --- | --- | --- | --- | --- |

| 6.2 | 隐私政策与个保法合规 | 独立隐私政策；最小必要采集；撤回授权即停采（03 号文规范四 §4.4）；摄像头/麦克风/蓝牙权限逐项声明用途 | PM | W6 初稿，W10 定稿 |
| 6.3 | 算法备案 | Phase 1 推荐用热度排序不涉个性化算法，暂免；Phase 2 上推荐算法前必须备案 | PM | Phase 2 前置 |

| 6.8 | 未成年人保护 | 青少年模式（使用时长/内容过滤）；支付需监护人验证 | PM + 前端 | W10 |
