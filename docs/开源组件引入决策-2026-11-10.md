# Mim 开源组件引入决策记录（ADR）

> 调研来源：2026-11-10 Gitee Explore 全量扫描，详见 [gitee-开源项目适配清单-2026-11-10.md](./gitee-开源项目适配清单-2026-11-10.md)。
>
> 本文件回答两个问题：**Mim 缺什么能力？缺的部分该引入哪个开源项目 / npm 包？**
>
> 原则：Mim 刻意精简（自写路由、自写 CSS、无 UI 库），**不预先装死依赖**——以下包均标注「触发条件」，等对应模块真正开发时再 `pnpm add` 并提交锁文件（铁律五）。

---

## 1. Mim 模块现状与缺口对照

| Mim 页面 / 模块 | 现状 | Gitee 调研发现的缺口 | 引入方向 |
|---|---|---|---|
| `Store.tsx` 商城 | 两级分类树 + 付费模块；依赖链已用 `@antv/g6` 画 dagre 有向图、价格历史已用 `echarts` 画折线 | 无支付收款（依赖链可视化、价格趋势已落地） | jeepay（独立支付网关） |
| `ComicWorkbench.tsx` 漫剧工作台 | 剧本→分镜→生图→成片；脚本草稿已用 `vditor` Markdown 分屏编辑器 | 图片无超分（Markdown 脚本编辑已落地） | Real-ESRGAN（图片超分） |
| `Chat.tsx` 聊天 | ws 连接 + 视频通话 | 无 AI 知识库问答、无 RAG | MaxKB / ragflow（独立部署外挂） |
| `Login.tsx` 登录 | 手机验证码 + 管理员密码 | 无图形/行为验证码防刷 | AJ-Captcha（含 React 源码，自部署） |
| `Deployments.tsx` | 部署矩阵取证展示；状态分布已用 `echarts` 环形图呈现 | 无时间序列趋势图（状态占比饼图已落地） | `echarts` 大盘趋势（耗时/随时间演化） |
| `Sites.tsx` | 45 类模块目录；入口状态分布已用 `echarts` 环形图呈现 | 无低代码/大屏搭建 | go-view / DataRoom（产品形态参考） |
| `Settings.tsx` | 系统设置 | 无文件网盘/管理界面 | DocSys / go-fastdfs（独立外挂） |
| `services/mim-api` 后端 | express5 + better-sqlite3 + ws；`sharp` 缩略图端点、`exceljs` 订单 xlsx 导出已落地 | 无任务调度（图片处理、Excel 导出已落地） | `node-cron`/BullMQ |

| `@antv/g6` | ^5.1.1 | 商城模块依赖链关系图（`comic.genpack.basic→pro→team`） | ✅ 已接入：`Store.tsx` 详情面板 `DependencyGraph` dagre 有向图，已解锁绿/未解锁灰/当前蓝，下方保留状态清单 |
| `vditor` | ^4.0.1 | 漫剧脚本 Markdown 编辑器（所见即所得） | ✅ 已接入：`ComicWorkbench.tsx` 创建标签页 `ScriptEditor`（分屏预览、关 localStorage 缓存），AI 建议回填草稿可继续改写 |
| `@ai-editor/core` 或 tide | 漫剧脚本**AI 富文本**（AiEditor 1.8K 面向 AI；tide 380 是 Gitee 少见的 React+TS 原生） | ComicWorkbench 加 AI 辅助写作时 | 优先选 tide（React 原生）或 vditor |

| `cnchar` | 汉字拼音/笔画（漫剧角色名/剧本辅助） | 需要时 | Gitee cnchar（446★，TS） |

> **不引入**：React Router（现有自写 `router.ts` 已满足，见 `apps/web/src/router.ts`）；不引入任何 UI 组件库（Mim 自写 CSS 令牌）。

## 3. 后端 npm 引入计划（services/mim-api）

| 包 | 版本 | 用途 | 状态 |
|---|---|---|---|
| `sharp` | ^0.35.5 | 服务端图片处理（缩略图/格式转换/水印） | ✅ 已接入：`GET /api/v1/media/thumb` 按 `object_key`+`size` 出 WebP 缩略图（归属/保留期校验、非图片 400）；前端 `AssetPreview` 带 Bearer fetch BlobURL 内联预览、失败回退预签名原图，契约测试 2 例 |

## 6. 明确不引入

| 类别 | 原因 |
|---|---|
| RuoYi / pig / JeecgBoot / SpringBlade 等 Java 后台框架 | 技术栈与 Mim（Node+React）冲突，仅参考 UI 与数据模型 |
| OpenHarmony 原生组件（按钮/布局/菜单等 30+） | Mim 是 Web 项目，不做鸿蒙原生 App |
| Android/iOS 原生 SDK、支付宝/百度小程序、Cordova | 同上，Web 响应式覆盖 |
| jQuery / Bootstrap / Angular / layui | 技术栈过时，与 React 现代栈不符 |
| MySQL + Redis + ES 全家桶 | 违背 Mim SQLite 轻量单机定位 |
| Maven / Gulp 插件 | Mim 用 pnpm + Vite |

1. **P0 — 登录验证码**：引入 AJ-Captcha 思路，在 Login.tsx 加行为验证码（解决 Gitee 浏览时遇到的滑块痛点，也防 Mim 自己的登录被刷）。
2. **P0 — 支付网关**：部署 jeepay，打通商城付费模块（¥99/¥299/¥999）的真实收款。
3. **✅ P1 已落地 — 漫剧脚本编辑器**：`vditor@4` 已接入 ComicWorkbench 创建标签页 `ScriptEditor` 组件（分屏预览、AI 结果回填草稿）。
4. **✅ P1 已落地 — 商城依赖链图**：`@antv/g6@5` 已接入 Store 详情面板 `DependencyGraph` dagre 有向图；同面板 `PriceHistoryChart` 用 `echarts@6` 画价格历史折线。
5. **P2 — AI 知识库**：部署 MaxKB，给 Chat 加产品文档问答。
6. **✅ P2 已落地 — 图片处理与订单导出**：`sharp@0.35` 已接 `GET /media/thumb` 缩略图端点；`exceljs@4` 已接 `GET /orders/export` 订单 xlsx 导出端点。

> 每完成一项，按铁律五把依赖写入 `package.json` + `pnpm-lock.yaml`，按铁律七更新本文件与 `docs/wiki/09-third-party-sdk-inventory.md`。
