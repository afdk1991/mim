Architecture

Headless 中台 + 多端薄壳

业务逻辑、能力网关、账号与数据下沉为共享层；各端只负责 UI 与平台 API 适配。改一处，所有端一致生效。

多端薄壳
Web、微信小程序、iOS / Android、Windows / macOS —— 仅承载界面与平台差异
共享业务层
账号与身份、功能模块商城、SaaS 工作区、通知与规则 —— 统一实现、统一治理
能力网关与驱动
IM、音视频、AI —— 以统一接口暴露，国内外差异由驱动层屏蔽
数据与合规
用户、账号、模块、权益、订单等共享业务对象；PIPL / GDPR 最小收集、可注销、可删除
P0 · 必须交付

核心用户旅程

注册账号 → 浏览模块商城并解锁 → 使用核心功能 → 跨端继续使用。

FR-01 账号与身份 P0

注册、登录、跨端账号打通。国内：手机号 + 微信 / 支付宝；海外：邮箱 + Google / Apple。

FR-03 核心 SaaS 工作区 P0

功能模块商城（模块上架、一次性解锁、权益与订单） + 漫剧 AI 剧（自动成片、创作工作台、作品分发、导出成片）。

FR-04 多端体验一致性 P0

Web、微信小程序、App、PC 至少一端可用，其余端适配；低于最低版本的系统不纳入支持范围。

FR-05 国际化与本地化 P0

i18n 多语言、多币种、多时区，国内与出海共用一套内容与计费模型。

FR-06 合规与隐私 P0

隐私政策、用户协议、数据收集清单、账号注销与数据删除请求，全流程可审计。
